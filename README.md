# Classifier API 

Локальный REST API для анализа тональности русского текста.

## 🚀 Что умеет
- Принимает текст на русском языке.
- Возвращает тональность (`positive` / `negative`) и вероятность (уверенность модели).
- Работает локально.

## 🛠 Стек
- Python 3.13,
- Flask (веб-сервер)
- PyTorch (CPU)
- Transformers (Hugging Face)
