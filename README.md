# Classifier API 

Локальный REST API для анализа тональности русского текста.

## 🚀 Что умеет
- Принимает текст на русском языке.
- Возвращает тональность (`positive` / `negative`) и вероятность (уверенность модели).
- Работает локально.

## 🛠 Стек
- Python 3.13,
- Flask (веб-сервер)
- PyTorch (CPU)
- Transformers (Hugging Face)

**Важно:** Из-за размера (680 МБ) веса модели не хранятся в Git-репозитории. 
Чтобы запустить проект, вам нужно отдельно скачать папку `rubert-classifier-full` и положить её в корень проекта (рядом с `web.py`).
